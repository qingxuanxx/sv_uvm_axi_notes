## 备考建议

1. **笔试范围比面试广**：SV/UVM 之外还要覆盖体系结构（cache/speedup/浮点）、数字电路、EDA 工具、脚本语言——**秋招前 1 个月专项刷**。
2. **找 bug / 情景题是重头**：练"读代码找错"和"分析不合理架构"的能力，不只是背语法。
3. 每套笔试做完要**复盘成考点**（参考上面表格），回马枪可能再考。
