## 使用说明

1. 每题先**手写**，跑通后再看别人的解法（面试白板环境=无编译器，平时要练到"手写能过"）。
2. 写完代码 + testbench 后，可提交到本目录（`手撕/答案/题目名.sv`），或提交到
   [systemverilog-learning](https://github.com/qingxuanxx/systemverilog-learning) 对应章节。
3. 状态跟踪：在题目表格的"状态"列自行标注 未做 / 已做 / 已跑通 / 面试被问。
