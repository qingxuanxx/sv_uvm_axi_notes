# 场景设计题

> 验证岗面试的**隐藏第二重点**（仅次于项目/八股）：给一个模块/场景，现场设计验证方案。
> 无法靠背，靠验证思维：**拆 feature → 分测试点 → 设计 corner case → 排障思路**。
>
> 面经来源：`../面经/` 各公司面经中"场景设计"类问题（持续收录）。

## 是什么

面试官给一个模块（或一个故障现象），要求现场说清"怎么验证 / 怎么排查"——考的不是代码，是验证方法论和工程思维。

## 题型分类

### 1. 模块验证方案设计（正向）

| 题目 | 公司 · 岗位 · 性质 |
|------|-------------------|
| 给定一个模块，如何开展验证、如何拆分 feature、如何分解测试点 | 字节跳动 · AI芯片验证 · 一面（随堂小测） |
| 关键模块 feature 如何验证 | 大疆 · 数字IC验证 · 校招 · 二面 |
| 输出 AHB 寄存器的验证计划，列出关键测试用例 | 沐曦 · 数字IC验证 · 校招 · 笔试（简答） |
| 寄存器验证思路以及对应测试用例 | 沐曦 · 数字IC验证 · 校招 · 笔试（简答） |

### 2. 故障排查（反向定位）

| 题目 | 公司 · 岗位 · 性质 |
|------|-------------------|
| SOC 中 AXI-Lite 寄存器回归测试间歇性失败，rdata 偶尔晚一拍：分析可能原因、定位思路与排查步骤 | 沐曦 · 数字IC验证 · 校招 · 笔试 |
| scoreboard 不匹配问题原因排查（三小问），及规避复现的方案（留档、与设计侧对齐） | 沐曦 · 数字IC验证 · 校招 · 笔试 |
| 新人用 config_db 连接动态事务，分析不合理点并给出新架构 | 沐曦 · 数字IC验证 · 校招 · 笔试（情景题） |

### 3. 设计权衡（工程判断）

| 题目 | 公司 · 岗位 · 性质 |
|------|-------------------|
| UT 验证与 SOC 验证的区别及侧重点 | 大疆 · 数字IC验证 · 校招 · 二面 |
| EDA 工具验证存在的局限性 | 大疆 · 数字IC验证 · 校招 · 二面 |

## 答题框架（自用模板）

```
拿到一个模块/故障，按四步走：
1. 拆 feature：这个模块"要做什么"拆成 3~5 个功能点
2. 分测试点：每个 feature 对应哪些测试点（正常/边界/异常/随机）
3. 定验证策略：定向 vs 约束随机；需要哪些 checker/覆盖率
4. 排障思路（故障题）：现象 → 缩小范围（波形/日志/单测）→ 定位 → 修复 → 回归留档
```

> 提示：自己的验证项目（如 AXI4→AXI4-Lite）就是现成的场景设计素材——能把自己的项目按这套框架讲清楚，面试场景题就通了。
