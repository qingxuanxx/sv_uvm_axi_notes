### Router 验证方向

| 问题 |
|------|
| 多端口并发传输时的功能正确性验证方法，量化验证指标而非仅靠波形判断 |
| 内部仲裁器的验证合理性 |
| FIFO 深度选择的验证衡量标准 |
| 多级 FIFO 场景：下级未存满、上级出现反压的情况验证 |
| noc_pkg 大小的影响，包中间是否支持反压 |
| 多输入同时经过 Router 的场景测试与实现方式 |

### 性能指标

- AXI 带宽与 latency 的确定方法
- 候选人：带宽利用率 53% 左右，瓶颈在 NOC 网络时钟过低无法跑满 DDR 带宽
- 多主机 outstanding 场景下可利用两片 DDR 的带宽
- NoC 中 DDR 放置位置对称最优的设计考量

### 功能覆盖率

- 除 AXI 部分外还需覆盖网络主干的测试完整性
- 各节点测试到位的判定方法

### 八股

- UVM 的层次结构介绍
- 代码覆盖率与功能覆盖率的分类，是否做过断言验证
- Python 中正则表达式 `re.match()` 与 `re.search()` 的区别（match 从头匹配，search 全文搜）
- SV 与 C 模型的交互方式：DPI 中 SV 数据结构与 C 代码入参的对齐方法（队列首地址指针、复杂结构体入参）
