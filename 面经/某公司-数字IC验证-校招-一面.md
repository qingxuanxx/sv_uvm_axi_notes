# 某公司（上海） 数字IC验证岗 面经

> 来源：小红书 | 26届 | 时长：30分钟 | 难度不大，面试官和蔼
>
> "一般经历五场面试后就能基本摸清通用考察范围。"

【面试结构】

自我介绍 → 实习项目 → AXB 项目 → 通用八股

【一、自我介绍环节】

- 研究生期间的研究课题
- 秋招是否只投递验证岗，是否考虑 FPGA 或 IC 设计方向
- 目前手上的 offer 情况

【二、实习项目】

提问偏向表层，没有过度深挖。

| 类别 | 问题 |
|------|------|
| 寄存器模型 | 配置方法 |
| 参考模型 | 如何确保 DUT 行为与 C 参考模型一致，二者对比方式 |
| DPI-C | 接口的定义与作用 |
| UVM 组件 | 项目包含哪些 |
| sequencer ↔ driver | 交互逻辑 |
| monitor | 采样数据流向，验证环境能否省略 monitor |
| Debug | 3 个 bug 的发现过程；输出异常时定位 DUT 还是环境问题的方法；第一处理步骤 |
| 寄存器 | 配置与测试是沿用标准流程还是自主编写 |
| 覆盖率 | 代码覆盖率 97% 是否达标，无法达到 100% 的原因 |
| APB | 一次操作至少几个周期，是否带有 PREADY 信号；项目中是否用了 VIP |
| UART | 协议核心内容；如何构造 FIFO 溢出测试场景 |

【三、AXB 项目（AXI 协议）】

| 问题 |
|------|
| AXI 原子操作的含义 |
| 128bit → 64bit 位宽动态转换的场景构造 |
| 非对齐传输（unaligned transfer）的定义 |
| AXI 协议为什么存在 4K 边界限制 |

【四、通用八股】

- Verilog 与 SystemVerilog 的区别，SV 相比 Verilog 的核心优势
- 数字设计能力水平
- 1bit 数据打五拍的 `always` 块写法
- 为什么选择从事验证工作

【候选人建议】

- 复盘好简历上**所有项目**，面试前全面预判可能的问题
- 经历五场面试后基本能摸清通用考察范围
- 路科项目推荐 **AXB 项目**：基于通用 AXI 协议，面试官感兴趣且考察概率高，围绕 AXI 基础 + 协议特性验证，**性价比极高**
