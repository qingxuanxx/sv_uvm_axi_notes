# 小米 ASIC验证 实习面经

> 来源：小红书 | 2026届 | 时间线：3.19一面 → 3.30二面 → 3.31 HR面

【一面：技术面（3.19，20分钟）】

面试氛围轻松，提问围绕项目与个人经历展开。

▸ 实习相关

- 简单 UVM 平台包含的组件
- 各组件之间的配合逻辑
- 代码覆盖率收敛的处理方法

▸ 反问

| 问题 | 
|------|
| 实习生培养模式 |
| SoC 验证与 IP 验证的区别 |
| 对新人的建议 |
| 岗位主要职责 |
| 面试结果通知时间 |

> 候选人还提出了自身学习的困惑，面试官给了很多建议。

【二面：技术面（3.30，30分钟）】

▸ 实习相关

- 子模块的主要验证功能
- C++ 开发测试用例的要求
- 验证岗位需要提升的能力
- 实习期间最大的提升

▸ 项目相关

- 挑选一个项目介绍基本功能与主要工作
- 是否有独立搭建验证环境的经验
- 对 UVM 的理解

▸ 其他

- 实习期间的工作时间
- 想要更换实习的原因
- 可实习的时长
- 实习期间的预期收获

▸ 反问

- AI 对行业的影响
- 实习期的主要工作方向
- 面试结果通知时间

【HR 面（3.31，10分钟）】

电话形式，简单询问工作时间、学校任务安排、实习原因等。

【关键收获】

- 小米面试整体轻松，一面才 20 分钟
- 面试中主动提学习困惑反而拉近距离
- 时间线极快：3.19 → 3.30 → 3.31，三周走完
