# 乐鑫科技 数字IC验证 实习面试面经

> 来源：小红书 | 面试时长 1 小时 | 面试官友善，会引导作答

## 面试流程

1. **自我介绍**
2. **在校课程**：询问喜欢/厌恶的课程（应聘者答体系结构：cache、TLB、分支预测），追问 cache 的作用与优化方法
3. **项目一：FPGA 毕设**：
   - 项目主要内容
   - 选择 FPGA 加速的原因
   - 使用 Zynq 的理由
   - PS 端与 PL 端控制和数据传输实现方式
   - 数据传输接口、数据量级
   - 数据传输是否需要 CPU 介入
4. **项目二：验证项目**：
   - 项目背景、验证结构
   - **burst 长度如何验证**
   - agent 是否为自主编写
   - AXI 侧是否使用 VIP
   - scoreboard 如何完成数据比对
5. **八股**：
   - Makefile 包含内容
   - VCS 命令相关内容
   - **UVM 工厂机制（重点）**：工厂注册发生在编译阶段还是仿真阶段？
   - timescale：给定 `timescale 1ns/100ps`，计算 `#123.456` 的延时
6. **手撕代码**：使用 SV 函数实现功能，要求用两种不同方法完成
7. **反问**：项目方向、实习生培养方案、面试提升方向

## 关键收获

- 验证项目追问点：burst 长度验证方法、agent 自主性、VIP 使用、scoreboard 比对机制——**项目细节要准备到这一层**。
- UVM 工厂机制被重点考察（注册发生在**编译阶段**，`uvm_component_utils` 宏在编译时注册到 factory）。
- timescale 计算题：1ns/100ps 下 `#123.456` 按时间精度 100ps 舍入。
