【一、数字IC验证专业核心（重中之重）】

▸ 1. SV/Verilog 语法基础

- 组合逻辑 vs 时序逻辑写法
- `always` 各类触发条件
- 阻塞赋值 vs 非阻塞赋值：使用场景与区别
- 模块端口定义
- `interface` 接口基础用法

▸ 2. UVM 验证框架（高频考点）

| 考点 | 内容 |
|------|------|
| 组件生命周期 | `uvm_component` 生命周期 |
| 四大核心组件 | driver、monitor、agent、scoreboard 工作原理 |
| sequence | 启动方式 |
| config_db | 配置机制 |
| factory | 工厂机制 |
| phase | 阶段机制 |

▸ 3. 时序与时钟

- 建立时间、保持时间的**计算**
- 同步复位 vs 异步复位
- 跨时钟域 CDC（重难点）：
  - 两级同步
  - 握手同步
  - FIFO 同步

▸ 4. 覆盖率

- 代码覆盖率、分支覆盖率、条件覆盖率、**功能覆盖率**的定义
- 各类覆盖率的优化与提升方法

▸ 5. 总线协议基础

- APB、SPI、I2C 三大常用总线的基础时序与核心特点
- 乐鑫主打无线芯片，偶尔考简易总线时序分析

▸ 6. 实操简答题

- 简易 testbench 搭建思路
- 仿真报错排查方法
- 项目中死锁问题的定位与解决方案

【二、数字电路基础（选择题）】

- 触发器 vs 锁存器
- MOS 管基础
- FPGA 基础常识
- 逻辑化简
- 异步电路常见问题
