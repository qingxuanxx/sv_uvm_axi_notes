# 某TPU公司 IC验证岗 一二面面经

> 来源：小红书 | 一面 8.28 | 二面 9.3 | AI 训练芯片方向

---

## 一面（8.28）：纯八股，十大类考点

### 1. AXI 协议
- 总线整体理解、通道分类、传输种类
- outstanding 与 out of order 的概念
- AXI 与 AHB、APB 总线的核心区别

### 2. 验证流程
- 完整验证流程、验证入口与出口标准
- SVA 断言的作用

### 3. 工程管理
- 工程中使用 Python 脚本还是 Makefile 管理用例与环境

### 4. 文件结构
- 验证工程文件夹存放规范：agent、env、lib、tb_top、seq、test、C 代码的目录划分

### 5. 算法理解
- 梯度下降算法的原理（公司主营 AI 训练芯片，考察较灵活）

### 6. UVM 组件交互
- m_sequencer 与 p_sequencer 的关系
- driver 与 sequence 的握手机制
- 对 TLM 端口 port、export、import 的理解

### 7. phase 机制
- phase 机制的整体定义、自顶向下执行的 phase 分类
- run_phase 与 main_phase 的关系
- 在 main_phase 中执行 raise/drop objection 时 run_phase 是否会继续执行

### 8. config_db 机制
- 核心作用、各参数的含义
- 多层级组件对同一变量执行 set 操作时的生效规则

### 9. SystemVerilog 基础
- 数组结构分类
- function 与 task 的区别
- 面向对象编程的理解
- clocking block 的作用与意义

### 10. 覆盖率
- 代码覆盖率与功能覆盖率的关联
- 代码覆盖率高是否代表功能覆盖率一定高
- 代码覆盖率高但功能覆盖率低的场景分析方法

## 二面（9.3）：项目 + 性能验证

### 性能验证（AI 芯片特色考点）

| 问题 | 要点 |
|------|------|
| ISP 模块输入图像数据的带宽计算方式 | 分辨率 × 帧率 × 位宽 |
| ISP 模块最大带宽能力的测试方法 | 打满接口测极限 |
| 加速器算力的获取方式 | MAC 数 × 频率 |
| 验证最大 TOPS 指标的用例设计思路与关注点 | 饱和计算 + 功耗/时序边界 |

### 其他

- C 参考模型的调用方式：DPI-C 与 `$system()` 系统函数调用的区别
- AXIS 总线的接口分类，KEEP 信号的作用
- 验证工作中规划的重点与难点
- 从事验证工作的核心吸引力、长期职业规划

## 关键收获

- **AI 训练芯片公司必考**：算力/TOPS/带宽的性能验证方法
- 十大类考点 = 完美自测清单（AXI/流程/工程/算法/UVM/phase/config_db/SV/覆盖率）
- DPI-C vs `$system()`：前者是接口调用、可传参数；后者是命令执行
