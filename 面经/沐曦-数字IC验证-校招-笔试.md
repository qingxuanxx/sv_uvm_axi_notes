# 沐曦 数字IC验证 校招笔试（两套）

> 来源：小红书 | 共两套笔试

## 第一套

### 选择/多选（10 道）

- **automatic 关键字**：fork 启动三个 fork-join_none 线程打印输出，考察缺少 automatic 时线程共享变量导致的打印异常

### 简答（4 道）

1. **寄存器验证思路**以及对应测试用例
2. **滥用 config_db 通信的危害**，以及更合理的通信方式
3. **UVM 代码找 bug**
4. SOC 中 AXI-Lite 寄存器回归测试间歇性失败，**rdata 偶尔晚一拍**——分析故障可能原因、定位思路与排查步骤

## 第二套

- 先填写背景岗位信息、重新上传简历，支持双机位手机小程序作答

### 选择（10 道）

- 基础 SV、UVM，含 makefile 操作题

### 简答（4 道）

1. **情景题**：新人使用 config_db 连接动态事务，分析不合理点并给出新架构
2. 输出 **AHB 寄存器的验证计划**，列出关键测试用例
3. 对一段 **seq 和 test 代码 debug**，找出代码 bug
4. **scoreboard 不匹配问题原因排查**（三小问），并询问规避复现的方案（留档、与设计侧对齐等手段）

## 关键收获

- 高频考察点：**config_db 正确用法（滥用危害/动态事务连接）**、**寄存器验证思路与验证计划**、**UVM 代码 debug**、**scoreboard 不匹配排查**。
- 情景题/找 bug 题占比高——验证岗笔试不只考记忆，考**分析和定位能力**。
- "rdata 晚一拍"是典型时序/握手问题排查题（AXI-Lite 响应时序）。
- scoreboard 排查提到**留档、与设计侧对齐**——工程化处理手段，面试可讲。
