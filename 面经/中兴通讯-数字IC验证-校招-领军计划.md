# 中兴通讯 IC验证工程师（领军计划）一二面面经

> 来源：小红书 | 一面 1v2，两位面试官分别提问，45min | 二面综合面 30min

【一面：两位面试官】

▸ 面试官一

| 类别 | 问题 |
|------|------|
| 职业选择 | 项目包含设计类内容却选择验证岗的原因，对设计与验证工作的理解 |
| 项目 | 参与度最深的项目详细介绍 |
| 项目 | 项目功能范围、团队参与人数 |
| 质量 | 实习生能参与多模块验证的原因，如何保障验证质量——依赖流程还是自主添加检查 |
| 环境 | 验证环境基于现有框架继承还是自主开发 |
| PMBUS | 时序规范、信号线定义与完整时序 |
| PMBUS | 激励生成逻辑：主机发送 8bit 数据后等待从机应答，应答信号判断逻辑 |
| PMBUS | 总线不驱动时释放为高阻的代码实现 |
| 验证计划 | 制定方法，潜在风险梳理 |
| 寄存器 | 校验方式、校验执行的位置与流程 |
| Debug | 项目中遇到的难度最高的 bug 详情 |

▸ 面试官二

| 类别 | 问题 |
|------|------|
| AXI 环境 | 验证环境开发语言，自主开发内容，项目当前完成阶段 |
| AXI 通道 | 通道分类；为何没有独立读响应通道但存在写响应通道；各通道核心信号线 |
| AXI 传输 | 传输类型介绍；valid/ready 依赖关系，ready 能否持续保持高电平 |
| AXI 对齐 | 对齐与非对齐传输，4bit 位宽下传输 7bit 数据需要几拍 |
| Sequence | 启动方式 |
| UVM Phase | 机制，耗时与不耗时 phase 区分，执行顺序；run_phase 与 main_phase 关联 |
| 寄存器模型 | 作用与结构 |
| 重载 | 对重载机制的理解，UVM 中的重载实现 |

【二面：综合面（30min）】

- 学校课题组与实验室基本情况
- 实习的工作时长、上下班时间
- 工作计划制定习惯：按任务内容还是按时间节点

【关键收获】

- 领军计划面试深度明显高于普通批次
- "为何没有独立读响应通道但存在写响应通道"——写响应需要反馈写状态，读数据通道本身承载了响应
- PMBUS 等小众总线如果简历写了就会问
