# 集益威 数字芯片验证工程师 一面面经

> 来源：小红书 | 27届秋招 | 投递 7.14 | 一面 8.6 | 时长 30min
>
> 全程基础八股，难度友好。

【一面问题】

| 类别 | 问题 |
|------|------|
| 数据类型 | logic、reg、wire 三者的区别 |
| 线程 | `fork join` / `join_any` / `join_none` 的区别 |
| 同步 | 是否使用过旗语（semaphore） |
| UVM 框架 | 验证环境的基本框架 |
| UVM 基类 | component 与 object 的区别 |
| UVM 配置 | 参数传递的方式 |
| AXI | 接口介绍与核心功能 |
| AXI | 读写是否支持乱序传输 |
| AXI | 是否会产生死锁，触发场景与解决方法 |
| 工具 | 工作中是借助 AI 还是自主编写 Python/Makefile 脚本 |
| AI | 本地是否部署了 AI Agent |
| 意愿 | 如果发放 offer，接受概率 |

【反问】

| 问题 | 回答 |
|------|------|
| 新人入职前半年工作内容 | 项目驱动培养模式，先接触 SerDes 或其他 IP 验证，导师带一两个项目后逐步独立 |
| SerDes 数字部分验证工作 | 过于专业，候选人未完全理解 |

全程八股，考点覆盖：数据类型、函数与任务、队列与动态数组、线程控制、同步通信机制、UVM 基类区别、总线协议、覆盖率。
