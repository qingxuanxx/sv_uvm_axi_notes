# 达摩院 数字IC验证岗 面经

> 来源：小红书 | 地点：上海

【面试流程】

```
部门主管面 → 交叉部门主管面 → 大领导面（非必设）→ HR面
```

【一面：部门主管 + 另一面试官】

- 主管围绕**项目**提问
- 另一面试官补充询问主管未覆盖的其他项目

▸ 技术考察

| 考点 | 内容 |
|------|------|
| UVM 多态 | 多态的概念 |
| virtual | virtual 的用法 |
| 父类/子类指针 | 指向规则 |

▸ 手撕代码

- 约束相关代码编写
- covergroup 相关代码编写

【二面：交叉部门主管面】

- 围绕项目提问
- AXI 总线核心特性
- 候选人优缺点自评

【HR 面 ⚠️ 重点提醒】

> **达摩院的 HR 权力很大，拥有一票否决权，不能轻视！**

| 注意点 | 说明 |
|------|------|
| 被问是否持有其他 offer | **一定要表现出强烈的入职意愿** |
| 谈薪 | 薪资不要开得过高，否则容易直接被淘汰 |
| 项目贡献 | 清晰说明自己在项目中的具体贡献 |
| 换工作原因 | 提前准备好合理理由 |

【关键收获】

- 达摩院 HR **一票否决权**，HR 面不能掉以轻心
- 谈薪不要贪，入职意愿 > 薪资期望
- 一面就有手撕代码环节（约束 + covergroup）
