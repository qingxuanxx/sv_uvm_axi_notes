# 芯原 上海数字验证岗 技术面面经

> 来源：小红书 | 三轮技术面，大厅集中面试 | 单轮约 20+ 分钟
>
> 面试官普遍迟到，设备偶有问题。像是基于固定题库提问，三轮有不少重复问题。面试官态度友好，压力很小。

【第一轮：项目细节】

- 项目中测试点的分解方法
- 功能覆盖率的 bins 设计，是否实现 cross 交叉覆盖率
- DUT 中 FIFO 的类型与深度设计
- 代码覆盖率与功能覆盖率的收集情况
- 未覆盖的点位与未覆盖的原因分析

【第二轮：协议 + UVM + 流程】

- AXI 协议基础八股
- 功能覆盖率与代码覆盖率的区别
- UVM 验证环境的整体架构
- 覆盖率 waive 文件的生成方式
- 脚本语言使用情况，是否具备脚本开发能力
- 系统级验证与 IP 级验证的差异对比

【第三轮（与前两轮重合度高）】

- AXI 八股
- UVM 与 SV 基础
- 脚本语言使用
- 覆盖率

【关键收获】

- 芯原三轮面试是独立面试官，所以会有重复问题——每轮都要完整回答
- 覆盖率 waive 文件、系统级 vs IP 级差异是不常见的考点
- 大厅集中面试形式比较特殊，设备可能出问题
