# 大疆 数字IC验证 校招/初级社招面试

> 来源：小红书 | 校招/初级社招

## 一面

- **phase 机制**、main 与 run 的区别，**二者在项目同时存在的风险**
- **factory 与 override 机制**
- **多种覆盖率区别**（要求结合项目作答）
- **寄存器模型**以及寄存器常用操作

## 二面

- 从手机芯片切入：是否对手机领域感兴趣、熟悉哪些手机芯片、芯片内部**面积占比最大和第二大的模块**
- **UT 验证与 SOC 验证的区别**及二者侧重点
- 针对简历芯片项目：项目竞争力、**关键模块 feature 如何验证**
- **EDA 工具验证存在的局限性**

## 关键收获

- 一面八股集中在 UVM 运行机制（phase/run-main/factory/覆盖率/寄存器模型）——都是 ch5~ch8 的核心。
- 二面偏 SOC 视野：模块面积占比、UT vs SOC 验证、EDA 工具局限——**考工程格局，不只是会搭平台**。
- "feature 如何验证"是场景设计题的变体，要会从功能点拆验证方案。
