# 小鹏汽车 SOC验证工程师 秋招面经

> 来源：小红书 | 27届秋招 | 投递：7.10 | 一面：8.7 | 二面：8.18 | 地点：四川
>
> "目前面试体验最好的一家公司，面试官温柔友好，遇到不会的问题会告知答案"

【一面（40分钟）】

面试主要围绕项目经历展开。

▸ 项目相关

- 项目里最熟悉或者学到最多的是哪一部分
- 怎么发现项目中的 bug
- 对相关协议的了解，大概说明协议里认为重要的内容
- AXI VIP 自带的覆盖率使用了哪些种类
- 有没有自己补充额外的覆盖率
- 从 reference model 到 scoreboard 的过程中，scoreboard 获取 transaction 用到了哪些方法
- scoreboard 拿到 transaction 时，发现 transaction 内容都一样可能是什么原因

▸ 基础八股

- `function` 和 `task` 的区别
- `main_phase` 和 `run_phase` 的区别
- 如果 `main_phase` 写了 `raise_objection` 但 `run_phase` 没有写，`run_phase` 是否可以正常运行
- 有没有用过 virtual 相关内容，简单说明如果 virtual function/task 里没有 virtual 关键字会出现什么问题

▸ 反问

| 问题 | 回答 |
|------|------|
| 新人前半年承担什么工作 | 看入职时项目进度，项目不密集安排培训，项目紧急可能直接投入具体工作 |
| SoC 验证相比模块验证需额外掌握什么 | 没有特别多额外要求，SoC 验证也是分模块开展；共通点：模块都需要访问 DDR、中断会同步到 CPU 侧检测；需大概了解模块间交互逻辑，非硬性要求，边做边学 |

【关键收获】

- 面试官遇到候选人不会的问题会**主动告知答案**，体验极佳
- SoC 验证 ≠ 什么都懂，也是分模块分工的
- DDR 和中断是 SoC 层面的通用知识
