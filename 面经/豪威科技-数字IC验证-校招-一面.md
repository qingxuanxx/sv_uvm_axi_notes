# 豪威科技 IC验证 一面面经

> 来源：小红书 | 结果：感觉不会有二面
>
> "目前压力最大的一家，面试官提问水平最高，问题一提出来就让人紧张，深度拉满"

【面试形式】

所有内容在**共享白板**上进行，需要现场画图、写代码。

【一、项目深度考察】

▸ 画出设计结构与验证环境

- 挑一个最熟悉的 UVM 环境验证项目
- 画出设计结构 + 验证环境
- 讲清楚**每个子模块的功能**、内部有哪些寄存器、数据流向
- ANA_PHY 的作用

▸ 对 DUT 讲解验证环境搭建

▸ 描述 case 完整运行流程

从以下步骤逐一展开：

1. `build_phase`、`main_phase`、`configure_phase` 中 AXI VIP 和 APB VIP 的配置
2. 寄存器是怎么通过 APB 相关 sequence 写进去的
3. `virtual sequencer` 怎么调度多个 AXI sequence
4. 现场写 AXI VIP 发数据包的**配置和随机化代码**

【二、八股考察（9 个考点）】

| # | 考点 | 说明 |
|---|------|------|
| 1 | 父类句柄 vs 子类句柄 | 互相赋值，结合代码题分析输出 |
| 2 | `rand` vs `randc` | 类型区别 |
| 3 | 四值逻辑 vs 二值逻辑 | 初值问题 |
| 4 | `fork_join_none` | 代码题，分析输出结果 |
| 5 | constraint 约束 | `dist` 的几种权重约束 |
| 6 | `config_db` | 四个参数含义 |
| 7 | `task` vs `function` | 区别 + 参数输入类型 |
| 8 | 交叉覆盖率 | 相关知识点 |
| 9 | AXI / AHB 时序图 | **现场画** |

【三、反问】

- 验证团队分布：上海和成都
- 上海 base 约 15 人
- 业务方向：SerDes、视觉芯片等

【关键收获】

- 豪威面试**极其硬核**：共享白板画图+写代码+手画时序图
- 项目要能讲清楚完整数据流，从 VIP 配置到 sequence 调度
- UVM 八股考察非常细：参数含义、代码输出分析，不是背概念就行
