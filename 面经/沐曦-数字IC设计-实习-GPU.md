# 沐曦 数字IC设计（GPU部门）实习面经

> 来源：小红书 | 岗位：GPU 部门 Memory Controller 方向 RTL 设计实习
>
> 候选人背景：双 985 科班，无论文无竞赛，纯小白 | 现场面试，1 位面试官，约 1h10min

【技术问题】

▸ 低功耗与时序

- 前端设计环节的低功耗设计方法
- 提升主频的技术手段

▸ 控制与数据通路

- 控制通路的实现方式与设计考量
- 流水线中处理**反压**的逻辑，触发反压的典型场景
- Memory 地址读写的控制逻辑

▸ 信号与时钟

- 毛刺的处理方法
- 多时钟域的处理方法（⚠️ 候选人无相关经验，成为短板）

▸ 工具与语言

- 是否使用过 SystemVerilog、掌握哪些特性
- SDC 约束设置
- Makefile 中的常用变量与用法

【反问】

- 项目内容
- 团队规模

【复盘】

> 面试重点集中在**访存细节**上，自己没有抓住考察重点。
> 设计实现相关知识储备不足、准备不充分。
> 多时钟域相关没有项目经验，基础问题答完后面试就结束了。

【关键收获】

- GPU 部门 Memory Controller 方向会深挖访存细节
- 多时钟域是硬伤，没做过也要提前学
- 低功耗设计、反压机制是设计岗高频
