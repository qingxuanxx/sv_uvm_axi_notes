# 华为海思 数字芯片 暑期实习面经

> 来源：小红书 | 流程：笔试 → 测评 → 一面技术 → 二面主管 → 入池
>
> 4月中旬笔试 → 次日测评 → 五一前后两轮面试

【笔试】

- 有一定难度
- **建议笔试时记下题目，考完尽快复盘**（一面可能复盘笔试题）

【一面：技术面（1小时）】

▸ 1. 自我介绍 + 笔试复盘（~2分钟）

- 学校、专业、重点项目经历
- 复盘几道笔试题目
- 部分候选人可能不问笔试

▸ 2. 项目介绍 + 随机提问

- 介绍项目与实习经历
- 面试官穿插提问项目相关八股与细节
- ⚠️ 若岗位与过往经历匹配度高，提问非常深入，会一直问到答不上来为止
- **简历上的项目务必全部吃透**

▸ 3. 手撕代码

- 随机抽取一道常规题目，难度偏低，侧重基础
- 重点练习：**FIFO、序列检测、流水线乘法器**
- 推荐平台：牛客、HDLBits

▸ 4. 反问

【二面：主管面（30分钟）】

| 环节 | 内容 |
|------|------|
| 自我介绍 | |
| 技术问题 | 结合项目，复习到位即可 |
| 主管常规 | 职业规划、个人优缺点、团队协作经历 |
| 反问 | |

> 回答时建议结合岗位需求，突出自身优势。

【关键收获】

- 笔试完立刻复盘题目，一面可能回马枪
- 简历项目**全部吃透**，会追问到答不上来为止
- 手撕代码难度不高，FIFO/序列检测/流水线乘法器是海思高频
