# 寒武纪 26届校招 验证岗 完整面经

> 来源：小红书 | 岗位：验证岗 | 工作地点：北京、上海、西安
>
> "寒武纪对应届生来说是非常好的成长平台"

【工作地点分析】

| Site | 情况 |
|------|------|
| **北京** | 公司大本营，hc 最多，IP 与 SoC 方向均有覆盖，**建议优先选择** |
| **上海** | 团队规模较小，只有两个 SoC 组，竞争更激烈 |
| **西安** | - |

【面试流程（共四轮）】

▸ 一面：技术面（节奏较快）

- 项目介绍（课题组 + 实习项目）
- 发散性考察知识广度：
  - 是否了解 DDR 等接口协议
  - ECC 纠错机制（不了解也没关系，面试官："工作以后有需要现场学就行"）
- 反问：培养计划 → **导师制**，先做虚拟项目，再进入实际项目

▸ 二面：技术面（~30分钟）

- 以项目为主
- 科研主题的意义
- 对项目风险的评估

> 反问：如何看待寒武纪突飞猛涨的股票 → 寒武纪踏实做事叠加 AI 行业趋势带来的市场情绪

▸ 三面：HR 面

- 聊得比较愉快
- 是否有对象
- 未来发展规划

▸ 四面：总监面（压力面）

- 不太关注技术细节，但**压力感较强**
- 从简历挖掘过往经历中的挑战、做得不够好的地方
- 会问性格相关问题
- ⚠️ 四面后还有一次和总监短暂交流的机会——实际日常沟通非常热情温和，面试中只是考察抗压能力

【结果】

应届校招统一薪资，受 hc 限制暂时只能选北京 site。

【关键收获】

- DDR、ECC 等知识不必全会，面试官看重学习能力
- 总监面有压力≠面试官不友善，抗压能力是考察点
- 北京 hc 多，不要因为地点放弃好平台
